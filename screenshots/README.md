# Screenshots

No screenshots are included yet. The environment this repository was
assembled and validated in had no browser/display available to actually run
`npm run dev` and capture the rendered UI — everything on the frontend was
verified via TypeScript compilation checks and code review, not visually
(see `docs/setup.md` "What was and wasn't actually tested").

To add real screenshots before submission:

1. `cd frontend && npm install && npm run dev`
2. Open `/dashboard` (and any other pages you've wired up)
3. Capture and save here as `dashboard.png`, `alerts.png`, etc.
4. Reference them from the root `README.md`, e.g.:
   ```markdown
   ![Dashboard](screenshots/dashboard.png)
   ```
